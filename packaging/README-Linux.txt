CircleMoon - Castlevania: Circle of the Moon, native for Linux

1. Make the AppImage executable: chmod +x CircleMoon-*-Linux-x64.AppImage
2. Run it. Click "Choose ROM..." and pick your own dump of Castlevania: Circle of the Moon (USA).
   CircleMoon checks the file and remembers where it is. It never copies or uploads it.
3. Settings (F1) > Game > Shortcut adds an applications-menu or Desktop entry that starts the
   game directly.

Settings, saves and save states are kept in:
  ~/.local/share/CircleMoon/CircleMoon/

CircleMoon does not include any game, BIOS, artwork, fonts or music from Konami.
